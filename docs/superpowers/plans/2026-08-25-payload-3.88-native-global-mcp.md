# Payload 3.88 Native Global MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the Admin application to Payload 3.88.0 and replace the custom SiteConfig MCP resource/tools with the plugin's native Global `find` and `update` capabilities.

**Architecture:** Keep the existing collection and task-oriented Post/Page MCP configuration intact, add a focused native Globals configuration module, and remove only the custom SiteConfig integration. Pin the complete Payload package family to 3.88.0, use a Payload-compatible Next.js version in Admin, and verify both the generated MCP API key schema and the full Admin application.

**Tech Stack:** Payload CMS 3.88.0, `@payloadcms/plugin-mcp`, Next.js 15.4.11, React 19.1.2, TypeScript, Vitest, pnpm 11.23.0.

---
